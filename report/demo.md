# SCADA系统演示文档

## 项目概述

这是一个基于C++11和Qt 5.15的SCADA（监控与数据采集）系统演示项目，用于展示设备监控、数据采集和实时监控的核心功能。

### 系统架构

#### 系统整体架构图

```
+-------------------+      +-------------------+      +-------------------+
|  设备模拟器        |      |  主站服务器        |      |  Qt客户端          |
| (device-simulator)|      | (master-server)   |      | (qt-client)       |
+-------------------+      +-------------------+      +-------------------+
        │ JSON:模拟设备端口          │ TCP:5002/5003              │
        ▼                      ▼                          ▼
+-------------------+      +-------------------+      +-------------------+
|  协议层            |      |  业务逻辑层        |      |  用户界面层        |
| - JsonProtocol     |      | - pipeline        |      | - 实时监控         |
| - Iec104Protocol   |      | - storage         |      | - 数据可视化       |
| (预留)            |      | - push            |      | - 设备管理         |
+-------------------+      +-------------------+      +-------------------+
        │                      │ MySQL                  │
        ▼                      ▼                        ▼
+-------------------+      +-------------------+      +-------------------+
|  数据库            |      |  网络通信          |      |  用户交互          |
| (MySQL)           |      | - TCP Server      |      | - 登录系统         |
|                   |      | - TCP Client      |      | - 告警管理         |
+-------------------+      +-------------------+      +-------------------+
```



**文字描述：**
这个架构图展示了SCADA系统的三个主要组件及其层次结构：
- **设备模拟器**：负责模拟SCADA设备行为，通过JSON协议与主站通信，从MySQL加载设备配置
- **主站服务器**：处理设备数据，存储到MySQL数据库，并向Qt客户端推送数据，包含多个功能模块
- **Qt客户端**：提供用户界面，包括实时监控、数据可视化、设备管理、告警管理等功能

系统采用分层设计，包括协议层、业务逻辑层和用户界面层，各层之间通过明确的接口进行通信。

#### 组件交互图

```
+-------------------+      +-------------------+      +-------------------+
|  设备模拟器        |      |  主站服务器        |      |  Qt客户端          |
+-------------------+      +-------------------+      +-------------------+
        │ JSON:模拟设备端口          │ TCP:5002              │ TCP:5003
        ▼                      ▼                      ▼
+-------------------+      +-------------------+      +-------------------+
|  发送设备数据      |      |  接收设备数据      |      |  接收实时数据      |
|  (JSON格式)        |      |  存储到MySQL      |      |  显示监控界面      |
+-------------------+      +-------------------+      +-------------------+
        │                      │                      │
        ▼                      ▼                      ▼
+-------------------+      +-------------------+      +-------------------+
|  设备状态更新      |      |  数据处理与转换    |      |  用户操作响应      |
+-------------------+      +-------------------+      +-------------------+
        │                      │                      │
        ▼                      ▼                      ▼
+-------------------+      +-------------------+      +-------------------+
|  预留IEC 104接口   |      |  推送数据到Qt      |      |  发送控制指令      |
+-------------------+      +-------------------+      +-------------------+
```

**文字描述：**
这个交互图展示了各组件之间的具体交互流程：
1. 设备模拟器通过JSON协议向主站服务器发送设备数据
2. 主站服务器接收并存储数据到MySQL数据库
3. 主站服务器向Qt客户端推送实时数据
4. Qt客户端显示监控界面并响应用户操作
5. 用户可以通过Qt客户端发送控制指令
6. 主站服务器将控制指令转发给设备模拟器
7. 设备模拟器更新设备状态

#### 数据流图

```
+-------------------+      +-------------------+      +-------------------+
|  设备模拟器        |      |  主站服务器        |      |  Qt客户端          |
+-------------------+      +-------------------+      +-------------------+
        │ JSON数据流              │ 实时数据流              │ 控制指令流
        ▼                      ▼                      ▼
+-------------------+      +-------------------+      +-------------------+
|  生成模拟数据      |      |  解析JSON数据      |      |  接收实时数据      |
|  (温度、压力等)     |      |  存储到数据库      |      |  更新监控图表      |
+-------------------+      +-------------------+      +-------------------+
        │                      │                      │
        ▼                      ▼                      ▼
+-------------------+      +-------------------+      +-------------------+
|  状态监控          |      |  数据处理          |      |  告警显示          |
|  (在线/离线)       |      |  (过滤、计算)      |      |  (颜色变化)        |
+-------------------+      +-------------------+      +-------------------+
        │                      │                      │
        ▼                      ▼                      ▼
+-------------------+      +-------------------+      +-------------------+
|  协议转换          |      |  推送数据          |      |  用户控制操作      |
+-------------------+      +-------------------+      +-------------------+
```

**文字描述：**
这个数据流图展示了数据在系统中的具体流动过程：
- **设备模拟器**：生成模拟数据（温度、压力等），进行状态监控（在线/离线），并执行协议转换
- **主站服务器**：解析JSON数据，存储到数据库，进行数据处理（过滤、计算），并推送数据到Qt客户端
- **Qt客户端**：接收实时数据，更新监控图表，显示告警（颜色变化），并处理用户控制操作

数据流包括三个主要方向：设备模拟器到主站服务器的JSON数据流、主站服务器到Qt客户端的实时数据流，以及Qt客户端到主站服务器的控制指令流。

## 技术栈

### 核心技术
- **编程语言**: C++11
- **GUI框架**: Qt 5.15 (Widgets、Network、Charts)
- **数据库**: MySQL 8.x
- **构建系统**: CMake 3.16+
- **开发环境**: Qt Creator (Windows)

### 系统组件
1. **设备模拟器** (`device-simulator`)
   - 模拟SCADA设备行为
   - 通过JSON协议与主站通信
   - 预留IEC 104协议接口

2. **主站服务器** (`master-server`)
   - 处理设备数据
   - 存储到MySQL数据库
   - 向Qt客户端推送数据
   - 实现协议转换

3. **Qt客户端** (`qt-client`)
   - 实时监控界面
   - 数据可视化
   - 设备控制功能
   - 用户登录系统

## 颜色逻辑系统

### 状态颜色标识
- **绿色**: 正常运行状态
- **黄色**: 警告状态（参数接近阈值）
- **红色**: 危险状态（参数超出阈值）
- **灰色**: 设备离线/未连接

### 数据可视化颜色
- **实时曲线**: 蓝色（正常数据）
- **历史数据**: 浅蓝色（对比曲线）
- **告警阈值**: 红色虚线
- **警告阈值**: 黄色虚线

### UI颜色规范
- **背景**: 深灰色 (#2D2D2D)
- **面板**: 中灰色 (#3C3C3C)
- **文字**: 白色 (#FFFFFF)
- **按钮**: 蓝色 (#0078D7) - 正常，红色 (#E51400) - 危险操作

## 构建与运行

```bash
# 创建构建目录
mkdir build
cd build

# 配置项目
cmake -S .. -B . -DCMAKE_PREFIX_PATH="D:/soft/Qt/5.15.2/mingw81_64" -G "MinGW Makefiles"

# 编译项目
cmake --build .

# 启动顺序
# 1. device-simulator
# 2. master-server  
# 3. qt-client
```

这个演示项目完整展示了SCADA系统的核心功能，包括设备监控、数据采集、实时显示、远程控制等，体现了C++在工业自动化领域的应用能力。
