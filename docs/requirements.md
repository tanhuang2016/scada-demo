# 需求说明（设备中心模型）

## 1. 项目目标

构建贴近电力主站逻辑的 **软件演示系统**：围绕 **设备与测点** 完成采集、监控、告警、遥控与配置维护。

| 项 | 选型 |
|----|------|
| 语言 | **C++11**（全项目统一） |
| 界面 | Qt 5.15.2 |
| 构建 | CMake |
| 设备协议（当前） | **JSON 行协议**（TCP 5001），`JsonProtocol` |
| 设备协议（预留） | IEC 60870-5-104（端口 2404），`Iec104Protocol` 占位 |
| 业务库 | **MySQL**（非 SQLite，贴近企业主站） |
| 部署目标 | 主站运行于 Linux；开发期可在 Windows |
| 模拟 | 无真实硬件，由 `device-simulator` 充当子站 |

### 为何 MySQL

- 与 Java/MySQL 经验复用；支持多表关联与持续增长的历史/告警/日志。
- SQLite **仅**用于 Qt 本地偏好（窗口、最近查询等），见下文。

## 2. 功能范围

### 2.1 必须实现（第一版）

| 域 | 内容 |
|----|------|
| 配置 | 设备表、测点表；Qt 设备/测点 CRUD；启用/停用 |
| 通信 | JSON TCP 建链、周期 telemetry、JSON 遥控；离线 5s 重连；104 后续可选 |
| 监控 | 实时电压/电流/开关；在线/离线/告警配色 |
| 告警 | 电压 >235V、<215V；通信超时未收到数据 |
| 遥控 | 合闸/分闸；确认框；写操作日志 |
| 历史 | 遥测入库；Qt 曲线（1h / 24h / 自定义） |
| 日志 | 操作日志列表；可选系统日志 |
| 登录 | 模拟登录 admin/123456，主站内存校验 |

### 2.2 明确不做（第一版）

- 遥调、复杂权限、用户表、密码加密、多角色
- 真实硬件驱动
- Oracle/达梦等（仅 MySQL）

### 2.3 模拟器

- 默认 **3 台** 设备（RTU001–RTU003，见 [data-model.md](data-model.md)）。
- 每台：电压 215–235V 随机、电流 0–30A、开关合/分；可注入越限电压做告警演示。

## 3. 三端职责（摘要）

详见 [architecture.md](architecture.md)。

- **device-simulator**：104 子站，响应总召与遥控。
- **master-server**：读 MySQL → 104 主站 → 告警/入库 → 推送 Qt。
- **qt-client**：五页面 + 登录；业务写 MySQL 经主站或直接（实现时统一约定，推荐 **Qt 配置类请求走主站 API** 以保证单一数据源）。

## 4. Qt 客户端

### 4.0 界面实现方式

- 使用 **Qt Designer**（`.ui` 文件）完成窗口布局与静态控件。
- 业务逻辑、网络、告警样式在 `.cpp`；运行时动态控件在代码中创建并放入 `.ui` 预留容器。
- 规范详见 [coding-standards.md](coding-standards.md)。

### 4.1 页面

| 页面 | 功能 |
|------|------|
| 设备管理 | 列表、增删改、启用/停用、测点维护、测试连接（可选） |
| 实时监控 | 电压、电流、开关、通信状态、最后更新时间；绿/灰/红 |
| 告警列表 | 当前与历史告警 |
| 历史曲线 | 电压/电流趋势；1h、24h、自定义 |
| 操作日志 | 时间、设备、合闸/分闸、操作人、结果 |

### 4.2 登录（模拟）

- 默认：`admin` / `123456`
- Qt 将凭证发主站；主站 **内存字符串匹配**；无用户表
- 控件：用户名、密码、记住用户名、自动登录、登录/退出
- 与 SQLite 联动保存偏好

### 4.3 Qt 本地 SQLite

- 路径建议：`qt-client/data/client_config.db`
- 表：`user_preference`、`recent_query`
- 启动恢复窗口与最近查询；退出保存

## 5. 主站后台

### 启动流程

1. 连接 MySQL  
2. 加载 `device`、`point`  
3. 对启用设备按 `protocol` 字段选择 `JsonProtocol` 或 `Iec104Protocol`（104 未实现则跳过并告警）  
4. 接收遥测 → 告警判定 → 写 `telemetry` / `alarm`  
5. 推送 Qt；处理 Qt 遥控与登录请求  

### 告警类型

| 类型 | 条件 |
|------|------|
| 电压越上限 | > 235V（或测点上限） |
| 电压越下限 | < 215V（或测点下限） |
| 通信中断 | 超过配置时间未收到数据 |

## 6. 遥控流程

1. 用户点击合闸/分闸  
2. 确认对话框  
3. 主站经 `IDeviceProtocol` 下发遥控（当前为 JSON `control`）  
4. 模拟器执行并返校  
5. 写 `operation_log`（默认操作人 admin）  
6. 刷新界面  

## 7. 验收标准

| 项 | 标准 |
|----|------|
| 设备管理 | 可增删改设备与测点，MySQL 持久化 |
| 通信 | 主站连上模拟器；断线自动重连 |
| 监控 | 实时值正确；状态色正确 |
| 告警 | 越限与通信中断可触发并展示 |
| 遥控 | 合/分闸成功且有日志 |
| 数据 | 历史写入 MySQL，曲线可查询 |

## 8. 完整演示流程（终态）

1. 启动 MySQL，导入种子数据  
2. 启动 `device-simulator` → `master-server` → `qt-client`  
3. 登录 admin/123456  
4. 设备管理查看/新增设备  
5. 实时监控看到 3 台设备数据刷新  
6. 模拟器注入高电压 → 告警变红  
7. 遥控分闸 → 状态与日志更新  
8. 历史曲线查看 1 小时数据  
9. MySQL 中核对 `telemetry`、`operation_log`
