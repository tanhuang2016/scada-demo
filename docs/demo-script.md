# SCADA Demo 演示脚本

## 前置条件

1. MySQL 已启动，`scada_demo` 数据库已建表并执行过种子数据
2. 已构建三目标：`cmake --build build`
3. 三个终端窗口准备好

---

## 第 1 幕：设备上送 + 实时监控（30 秒）

### 步骤
```
终端1: .\build\bin\device-simulator.exe
终端2: .\build\bin\master-server.exe
终端3: .\build\bin\qt-client.exe
```

### 看什么
- **终端1**：5 台设备 TCP 服务启动，JSON 帧每秒输出
- **终端2**：MySQL 加载 5 台设备 → 连接成功 → `[遥测]` 日志每秒打印
- **终端3**：弹出登录框 → 输入 `admin` / `123456` → 登录
  - **实时监控 Tab**：5 张设备卡片，绿色"在线"，电压/电流/开关每秒刷新，数值各不相同
  - 偶尔会出现红色"告警"卡片（电压越限自动触发）

---

## 第 2 幕：遥控操作（30 秒）

### 步骤
1. 在 Qt 实时监控页，点击 RTU001 卡片的 **"分闸"** 按钮
2. 确认对话框点击"是"
3. 等待弹窗提示结果

### 看什么
- Qt 弹窗：`RTU001 分闸 成功`
- 卡片开关状态变为 **"分闸"**，电流降至 **0.00A**
- **终端1** 日志：`[RTU001:5001] 收到遥控: 分闸`
- 切换到 **"操作日志"Tab**：出现一条记录 admin / 分闸操作 / SUCCESS

4. 点击 **"合闸"** 恢复

---

## 第 3 幕：设备管理 + 热加载（30 秒）

### 步骤
1. 切换到 **"设备管理"Tab**
2. 查看 5 台设备列表
3. 选中 RTU001 → 点击 **"编辑设备"**
4. 切换到 **"测点配置"子Tab**
   - 修改电压上限为 230.00 → 保存
5. 回到实时监控 Tab，卡片自动刷新

### 看什么
- 设备列表显示全部启用设备
- 保存后主站热加载，重新连接
- 电压上限修改后，告警阈值生效

---

## 第 4 幕：告警演示（30 秒）

### 步骤
1. 观察 **"实时监控"Tab** 等待红色告警卡片出现
2. 切换到 **"告警列表"Tab**

### 看什么
- 红色告警卡片显示"告警"
- 告警列表：`VOLTAGE_HIGH` / `VOLTAGE_LOW` 记录
- ACTIVE 状态红色高亮，CLEARED 状态正常色
- 告警自动恢复（电压回归正常后）

---

## 第 5 幕：通信中断与恢复（30 秒）

### 步骤
1. **关闭终端1**（模拟器）
2. 等待约 3 秒

### 看什么
- **终端2**：`[离线] RTU001 连接已断开` + `[告警] RTU001 通信中断`
- **终端3**：所有卡片变灰"等待连接..."
- **告警列表Tab**：出现 `COMM_LOST` 告警

3. **重新启动终端1**
4. 等待约 5 秒

### 看什么
- 主站自动重连，卡片恢复绿色
- 通信中断告警自动 CLEARED

---

## 第 6 幕：历史曲线（30 秒）

### 步骤
1. 切换到 **"历史曲线"Tab**
2. 选择设备 `RTU001`，时间范围 `最近 1 小时`
3. 点击 **"查询"**

### 看什么
- 蓝色曲线：电压随时间变化
- 红色曲线：电流随时间变化
- X 轴为时间，Y 轴左为电压(V)，右为电流(A)
- 切换时间范围（24 小时 / 7 天）查看不同粒度

---

## 结束

所有终端按 Ctrl+C 退出。MySQL 中数据持久化保留。
