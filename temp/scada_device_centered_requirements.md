# 基于 IEC 104 的 SCADA 演示系统需求说明（设备中心模型版）

> 目标：构建一个贴近真实电力主站系统的软件演示项目。
>
> 技术栈：C++17 + Qt 5.15.2 + Linux + CMake + MySQL + IEC 60870-5-104。
>
> 核心思想：**整个系统围绕“设备”展开。** 所有通信、监控、告警、历史数据、遥控和配置维护，本质上都是对设备及其测点的管理。

---

# 一、为什么使用 MySQL 而不是 SQLite

虽然 SQLite 完全可以支撑演示系统，但为了更贴近真实企业项目，推荐使用 MySQL。

## 1. 企业主站系统的常见做法

实际工业系统通常使用：

- MySQL
- Oracle
- PostgreSQL
- 达梦数据库

## 2. 本项目采用 MySQL 的原因

- 更符合企业架构
- 展示数据库建模能力
- 支持多表关联
- 更贴近生产环境
- 对你已有的 Java/MySQL 经验可直接复用

## 3. 数据规模说明

设备配置数据本身不大，但：

- 历史遥测数据会持续增长
- 告警记录持续增长
- 操作日志持续增长

因此使用 MySQL 非常合理。

# 三、三个程序的职责

## 1. 设备模拟器（模拟现场设备）

模拟真实 RTU/配电终端：

- 监听 2404 端口
- 响应 IEC 104 连接
- 周期发送电压、电流、开关状态
- 接收遥控命令

---

## 2. 主站后台（核心业务服务）

系统的大脑：

- 从 MySQL 读取设备配置
- 根据配置建立 IEC 104 通信
- 接收实时数据
- 判断告警
- 保存历史数据
- 保存操作日志
- 将数据推送给 Qt 客户端

---

## 3. Qt 客户端（监控与配置界面）

用于展示和维护：

- 设备管理
- 实时监控
- 告警查看
- 历史曲线
- 遥控操作
- 日志查看

# 二十一、SQLite 本地配置需求（Qt 客户端） 

> 说明：系统主业务数据存储在 MySQL 中；Qt 客户端使用 SQLite 保存本地配置和用户偏好。

## 1. SQLite 数据库文件

建议文件名：

- `qt-client/data/client_config.db`

## 2. 使用场景

用于保存： 

- 用户首选项
- 主窗口大小与位置
- 最近选中的设备
- 历史曲线最近查询条件
- 是否自动登录
- 最近登录用户名

## 3. 建议表结构

### 用户首选项表（user_preference） 

| 字段名 | 中文名称 | 示例值 |
|------|------|------|
| 配置项名称 | 键名 | mainWindowWidth |
| 配置项值 | 值 | 1600 |
| 描述 | 说明 | 主窗口宽度 |

### 最近查询表（recent_query） 

| 字段名 | 中文名称 |
|------|------|
| 模块名称 | 历史曲线 |
| 开始时间 | 查询开始时间 |
| 结束时间 | 查询结束时间 |

## 4. 启动行为

Qt 客户端启动时： 

- 读取窗口大小与位置
- 读取最近登录用户名
- 读取默认监控设备
- 读取最近查询条件

## 5. 退出行为

Qt 客户端退出时： 

- 保存窗口大小与位置
- 保存当前主题
- 保存最近查询条件

# 二十二、登录功能需求（模拟登录） 

> 说明：仅用于完善系统演示流程，不需要用户表，不需要复杂权限管理。

## 1. 登录方式

Qt 客户端启动时显示登录窗口。

## 2. 默认账号

- 用户名：admin
- 密码：123456

## 3. 认证方式

- Qt 将用户名和密码发送给主站后台。
- 主站后台在内存中进行字符串匹配。
- 匹配成功返回登录成功。
- 匹配失败返回错误信息。

## 4. 不需要实现

- 用户表
- 密码加密
- 权限控制
- 多角色管理

## 5. 登录界面

包含以下控件： 

- 用户名输入框
- 密码输入框
- 记住用户名
- 自动登录
- 登录按钮
- 退出按钮

## 6. 与 SQLite 联动

登录窗口可使用 SQLite 保存： 

- 最近登录用户名
- 是否记住用户名
- 是否自动登录

## 7. 演示流程

1. 启动 Qt 客户端
2. 弹出登录窗口
3. 输入 `admin / 123456`
4. 登录成功进入主界面
